# Assets Directory

This directory contains static assets for the StoreScope application.

## Logo Files

Place your logo files here:
- `logo.png` - Main logo (recommended size: 200x50px or similar aspect ratio)
- `logo.svg` - SVG version of logo (preferred for scalability)
- `favicon.ico` - Browser favicon

## Usage

The logo is used in:
- Navigation bar (App.jsx)
- Login page
- Other branding locations throughout the app
